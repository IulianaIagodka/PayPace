# PayPace — посібник користувача / User guide

Payday → payday. Гроші = енергія. Додаток показує, скільки можна витратити **сьогодні**, і чи ти на **Pace** до зарплати.

---

## Швидкий старт

1. Відкрий PayPace і пройди онбординг: **баланс**, **дата зарплати**, валюта.
2. На **Home** дивись **Safe to spend today** — це твій денний ліміт.
3. Додай витрати: **+** → вручну, **скан чека**, або (Plus) імпорт виписки.
4. За бажанням розподіли пул по категоріях: **Allocate** (Plus).
5. Вкладка **Pace** — прогноз до payday і темп витрат.

---

## Вкладки

| Вкладка | Що робить |
|---------|-----------|
| **Home** | Баланс, safe today, прогрес до payday, картки категорій |
| **Trans** (Spend) | Витрати цього циклу по днях; **DEL** на рядку / **DEL DAY** на дні |
| **Pace** | LEFT TO SPEND NOW, прогноз IF THIS PACE → PAYDAY, темп (PACE), Day 1…N |
| **Settings** | Plus, shared budget, рахунки, цикл, категорії, privacy |

---

## Safe to spend today

Кожного ранку додаток **фіксує** денний ліміт з того, що лишилось до payday, поділеного на дні, що лишились.

- Витрати **сьогодні** з’їдають лише сьогоднішній ліміт.
- Недотрата сьогодні **не** роздуває завтра — залишок лишається «зарезервованим» на сьогодні.
- Перевитрата сьогодні одразу зменшує пул на майбутні дні.

Якщо день був порожнім і ліміт «залочився» в 0 — наступного ранку ліміт перераховується заново.

## Категорії

За замовчуванням (без сум, поки ти їх не виділиш):

**Home · Groceries · Eating out · Transport · Shopping · Kids · Health · Fun · Travel · Subscriptions · Other**

На Home і в списках показуються лише категорії, де є **витрати** або **виділений бюджет**. Порожні не засмічують екран.

### Картка категорії

| Ситуація | Що бачиш |
|----------|----------|
| Є виділення (Allocate) | **витрачено / план** (spent / planned) + прогрес-бар заповнення |
| Витрати є, бюджету ще немає | **spent / —** і порожній meter (без `0/0`) |

Plus: **Allocate** — розклади пул по категоріях. **Category balances** — деталізація витрат.

---

## Чеки (receipt scan)

1. Зроби фото чека (потрібна камера / Photos).
2. Додаток розпізнає рядки й суми.
3. **Один чек = одна категорія** (рядки можуть бути різні, але категорія спільна — береться домінантна за сумою; можна змінити вручну).
4. **Add everything** / збереження — один раз; повторний тап не дублює витрати.

**Free:** 3 скани. Далі — **Plus**.

---

## Pace (колишня Status)

- **LEFT TO SPEND NOW** — скільки ще можна витратити до зарплати (пул мінус bills / reserved / spent).
- **SAFE TODAY** — денний ліміт на сьогодні.
- **IF THIS PACE → PAYDAY** — прогноз на день зарплати, якщо витрачатимеш таким самим темпом (може бути мінус = DEFICIT).
- **PACE** — статус темпу (ON TARGET / DEFICIT / …).
- **Day 1 of N** — перший день циклу = 1, не 0. Якщо після Edit Budget знову «Day 1», а витрати старші — старт циклу підтягується до найранішої витрати.

## Free vs Plus

| Free | Plus |
|------|------|
| Баланс, safe today, дні до payday | Allocate по категоріях |
| Рахунки (bills) | Кастомні категорії |
| Ручні витрати | Безлімітні скани чеків |
| **3** скани чеків | Імпорт банківської виписки (CSV/PDF) |
| | Spend-by-category + історія |
| | Shared budget з партнером |

Підписка в Settings: **PLUS MONTHLY** / **PLUS YEARLY** / **RESTORE PURCHASES** (Apple StoreKit). У dev-збірці є **TRY PLUS (DEMO)**.

Деталі shared budget: [SHARED-BUDGET.md](./SHARED-BUDGET.md).

## Shared budget (Plus)

1. Один створює household → код запрошення.
2. Партнер вводить код у **Join**.
3. Баланс, payday, bills і витрати синхронізуються (Supabase Realtime + періодичний sync ~20 хв).

Сповіщення про зміни метрик — **локальні** на пристрої (без push / APNs).

---

## Поради

- Завжди оновлюй додаток з TestFlight після нового білду з `main`.
- Якщо скан чека падає — на екрані буде реальна помилка (ключ, білінг OpenAI, погане фото), не «фейковий» чек.
- Імпорт виписки (CSV або PDF) не вигадує витрати: якщо файл не парситься — помилка. Текст з PDF читається **на пристрої**. Прев’ю групує рядки **по днях** і показує суми **по категоріях**; кожна витрата зберігається зі своєю датою.
